# hedera-analytics

hedera-analytics is a Python toolkit for Hedera network analysis: a staking-rewards profiler, a mirror-node data refinery, and a Prolog fact extractor that turns account history into queryable logic facts.

## When to use

Analyzing Hedera accounts/staking in Python, or exporting mirror-node data for research.

## Install

```
pip install hedera-analytics
```
